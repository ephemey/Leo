Privacy Policy for Leo
Last Updated: July 2026

We take user privacy seriously. This policy outlines what data Leo collects, how it is stored and used, and how you can manage or delete your data.

1. Data We Collect
To provide core functionalities like the Chengyu Jielong (成语接龙) game, Karaoke Queue Management, and Chinese-English Dictionary Lookups, we collect minimal, non-sensitive Discord API data:

Discord User IDs (Snowflakes): Unique numerical identifiers used to link game stats, scores, and queue requests to your account.

Server (Guild) & Channel IDs: Identifiers used to maintain server-specific configurations, channel permissions, and custom game settings.

Gameplay & Usage Statistics: High scores, win streaks, and leaderboard data for the Chengyu game, as well as temporary active queue state for karaoke events.

Note on Message Content: We process message text in real time solely to evaluate idiom submissions during games, process prefix commands, and provide automated dictionary lookups. We do not read, store, or log private chat content or raw messages.

2. How We Use Your Data
Collected data is used strictly for the following purposes:

Maintaining persistent user scores, achievements, and server leaderboards.

Managing live voice/karaoke channel request queues and turn order.

Saving server-specific bot preferences set by administrators.

We do not sell, rent, monetize, or share your data with third parties or external data-brokers.

3. Data Storage & Security
Storage Location: All data is stored in a secure, restricted-access database hosted off-platform.

Retention: Game stats and server preferences are retained only for as long as the bot remains active in your server or until a deletion request is processed.

4. Opting Out & Data Deletion Requests
You have full control over your data. You can opt out of data collection or request the complete erasure of your stored data at any time.

How to Request Removal: Contact the developer directly on Discord via Direct Message

What Happens: Upon receiving your request, all associated Discord User IDs, scores, leaderboard entries, and personal preferences will be permanently wiped from our database within 5 business days.
